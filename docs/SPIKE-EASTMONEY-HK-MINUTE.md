## 周期覆盖（secid=116.00700 腾讯控股，2026-11-02 盘中实测）

| klt | 语义 | 实测深度 | 备注 |
|---|---|---|---|

| 5 | 5 分钟 | 1507 根 / 23 个交易日（09-29→11-02） | 约一个月窗口 |
| 15 | 15 分钟 | 502 根 / 同窗口 | |
| 30 | 30 分钟 | 251 根 / 同窗口 | |

| 101 | 日线 | 5515 根（2004-06-16 上市→今） | 全历史 |
| 102/103 | 周/月线 | 正常 | bar 时间戳 = 桶内**最后交易日**（与腾讯周/月线同口径） |
| trends2 `ndays=5` | 逐分钟走势 | 1655 点（10-27→11-02，5 个交易日） | 补 1m 历史；行内 open 位恒 0 |

**1m 深度合成**：klt=1（当日真 OHLC）∪ trends2（近 5 日重建段）⇒ 港股 1 分钟可用深度 ≈ **5 个交易日**。
trends2 行格式 `时间,0,收,高,低,量,额,均价`，open 由前一点收盘重建（首点取自身收盘；**前日收盘不能当 open**——会落到当日 [low,high] 之外）。

## 行格式（与腾讯同序，非标准 OHLC）

kline：`2026-11-02 09:31,387.600,388.000,388.400,384.600,801100,310143240.000,0.99`
= 时间,**开**,**收**,**高**,**低**,量,额,振幅 —— 收盘在第 3 位（`f52=open f53=close f54=high f55=low`，与 kline 腾讯口径一致）。

## 复权与其他

- `fqt=0` 不复权 / `fqt=1` 前复权；本实现分钟线用 fqt=0，日线族 fqt=1（对齐腾讯 qfq）。
- `dktotal` 字段是**日线总根数**（恒 5515），不是所查 klt 的序列长度——别当深度读数。
- 东财按**源 IP 限流**（会临时封突发）；上层 `pollSchedule` 已有退避，禁止绕过它高频拉取。

## 边界（照登）

1. 分钟线**无向左翻页**：`end=` 无效、`beg/end` 区间未探（窗口一次给全，`barsBefore` 恒空）。
2. 1m 只有 5 日；5m–60m 只有约 23 个交易日；更早只能切日线族。
3. trends2 重建段的 open 是近似值（前点收盘），当日段被 klt=1 真值覆盖。
